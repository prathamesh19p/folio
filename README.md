# Prathamesh Phalke Personal Website - React Version

A modern, responsive personal website built with React.

## 🚀 Features

- ⚛️ **React 18** - Modern React with hooks and functional components
- 📱 **Fully Responsive** - Optimized for desktop, tablet, and mobile devices
- ✨ **Smooth Animations** - Typing animation, fade-in effects, and interactive transitions
- 🎯 **Interactive Elements** - Hover effects, ripple animations, and smooth scrolling
- 🔗 **Social Media Integration** - Links to Twitter, GitHub, and email
- 🌟 **Performance Optimized** - Fast loading and smooth user experience

## 🚀 Getting Started

### Prerequisites

- Node.js (version 14 or higher)
- npm or yarn

### Installation

1. **Clone or download the project**
   ```bash
   git clone <repository-url>
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Start the development server**
   ```bash
   npm start
   # or
   yarn start
   ```

4. **Open your browser**
   - Navigate to `http://localhost:3000`
   - The website should load with all animations and interactive features

### Building for Production

```bash
npm run build
# or
yarn build
```
